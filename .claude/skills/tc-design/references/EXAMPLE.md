# [품질 앵커] TC 설계 결과 — 주차 정산기 요금 결제 (가상 도메인)

> 가상 제품이다. 입력·코드·반증 기록 모두 꼴을 보이려고 지은 것이고 실제 제품과 관계없다.
> 규칙: `TC_QUICKSTART.md` · 반증 라운드 2회 · lint 종료 코드 0

## 0. 입력 (발췌)

**기획 세부 문서 §3 요금 결제** — 주차권을 넣으면 요금을 보여 준다. 입차 후 20분까지는 무료. 카드 결제만 받는다. 결제가 끝나면 영수증을 고를 수 있다. 주차권을 못 읽으면 「주차권 오류」 안내.

**코드 — 문구 리소스**

```
pay.insert   = 주차권을 넣어 주세요
pay.fee      = 주차 요금
pay.free     = 무료 출차 시간입니다
pay.paid     = 결제가 완료되었습니다. 출차하실 수 있습니다
pay.cardfail = 카드 결제에 실패했습니다. 다른 카드를 사용해 주세요
pay.badticket= 주차권을 읽을 수 없습니다. 직원을 호출해 주세요
btn.card     = 카드 결제
btn.receipt  = 영수증 출력
btn.call     = 직원 호출
btn.cancel   = 취소
```

**코드 — 요금 로직** `FREE_MINUTES = 30`, 이후 10분마다 500원(올림). 카드 단말기가 거절을 돌려주면 `pay.cardfail` 을 띄우고 요금 화면에 남는다.

**티켓 `PROJ-0420` 코멘트(본문보다 최신)** — 「무료 시간은 운영사 요청으로 30분으로 바꿈. 기획서는 아직 20분.」
