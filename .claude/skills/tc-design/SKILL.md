# tc-design — 기획 문서 + 코드 → 실무 TC

입력 문서와 코드에서 **운영자 조작 하나에 TC 하나**를 뽑고, 작성 맥락을 모르는 감사자로 수행 가능성을 반증한 뒤, 검사기로 금지 패턴을 막는다. 규칙 정본 = [`TC_QUICKSTART.md`](../../../TC_QUICKSTART.md). 이 파일은 순서만 정한다.

## 좋은 산출물이란 (품질 기준)

- 처음 보는 테스터가 **시트만 보고** 상태를 갖추고, 조작하고, 판정할 수 있다.
- 화면 문구는 코드·캡처의 **글자 그대로**. 못 찾은 것은 `[확인 필요]` 로 남아 있다(지어낸 문구 0).
- 기획과 코드가 다른 곳은 Comment 에 「기획: … / 코드: …」로 드러나 있다. 한쪽으로 조용히 맞추지 않았다.
- 자동화용 기술 정보(응답 고정, 세는 횟수, 주소)는 시트가 아니라 **부록 note** 에 있다.
- 반증 라운드 기록(라운드 수, 라운드별 ❌ 수)과 `tc_lint` 종료 코드 0 이 결과에 붙어 있다.

## 절차

1. **입력 받기** — 기획 세부 문서, 코드 위치(화면 템플릿·문구 리소스·분기 로직), 티켓이 있으면 본문과 **코멘트 전부**. 코멘트가 본문보다 최신이다. 무엇을 어느 판으로 읽었는지 근거 목록에 적는다. 입력이 없으면 지어내지 말고 사용자에게 묻는다.
2. **화면 문구 목록 뽑기** — 코드의 문구 리소스와 템플릿 리터럴 **양쪽**에서 화면에 뜨는 문장·버튼 이름을 글자 그대로 모아 `screen-text.txt` 로 둔다(한쪽만 찾으면 「없음」으로 오판한다).
3. **초안** — 화면마다 운영자가 하는 조작을 나열하고 조작 하나에 TC 하나. 정상 경로 + 기획·코드의 예외 분기 + 경계값 + 돈·물건·안전에 닿는 것. 기획과 코드가 다른 곳은 이 단계에서 표시한다.
4. **문체 맞추기** — `TC_QUICKSTART.md §3` 칸 규칙. 기술 정보는 부록 note 로 옮긴다.
5. **사람 말로 다시 쓰기** — `§4`. 화면 문구·숫자·고유명사 보존, 분량 75~110%.
6. **반증 라운드** — 결과 표와 원본 소스 경로만 담아 **새 서브에이전트**를 띄운다. 브리핑은 [`references/AUDITOR_BRIEF.md`](references/AUDITOR_BRIEF.md) 를 그대로 쓴다. 작성 이유·가정·이 대화의 맥락은 넣지 않는다.
   - 돌아온 지적은 원문을 다시 열어 맞는지 본 뒤 채택한다. 근거 줄이 없는 지적은 버린다.
   - ❌ 가 하나라도 있으면 고치고 **새 에이전트로** 다시 돌린다(같은 에이전트에 「고쳤다」를 알리면 맥락이 샌다). ❌ 0 이 될 때까지. 표가 크면 화면 단위로 갈라 병렬로 던진다.
7. **금지 패턴 검사** — `python3 tools/tc_lint.py --self-test` 가 통과하는지 먼저 보고, `python3 tools/tc_lint.py <표> --screen-text screen-text.txt`. 종료 코드 1 이면 고치고 6 부터 다시(문장이 바뀌었으면 반증도 다시).
8. **결과표** — [`references/TEMPLATE.md`](references/TEMPLATE.md) 꼴로 낸다. 시트에 쓰라는 요청이 있으면 `TC_DESIGN_GUIDE.md §6` 서식으로.

## 언제 쓰지 말 것 (경계)

- 무엇을 테스트할지 아직 모름(커버리지 지도가 먼저) → `advise-test-coverage`.
- 릴리스 diff 로 영향 범위 산정 → `diff-driven-test` 로 범위를 낸 뒤 이 스킬로 TC 를 쓴다.
- 함수 단위 회귀 방어 → `write-unit-tests`.

## 출력 계약

`references/TEMPLATE.md` 구조:
1. **근거 목록** — 문서 판, 코멘트 날짜, 커밋.
2. **TC 표** — 템플릿 열 전부.
3. **부록 note** — 행별 기술 정보(시트에 안 들어감).
4. **기획·코드 차이 / `[확인 필요]` / 가정 목록**.
5. **반증 라운드 기록** — 라운드별 ✅/⚠/❌ 수, 고친 것.
6. **lint 결과** — 마지막 줄 그대로와 종료 코드.
